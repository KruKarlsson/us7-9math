ฮีโร่ตะลุยเลข ม.ต้น — วิธีนำขึ้นเว็บ
=====================================

ไฟล์ที่ต้องใช้มีไฟล์เดียว: index.html
(รูปตัวละคร ฉาก เสียง และโจทย์ทั้งหมดอยู่ในไฟล์นี้แล้ว ไม่ต้องมีโฟลเดอร์อื่น)

วิธีที่ง่ายที่สุด (ฟรี ไม่ต้องเขียนโค้ด)
1. เปิด https://app.netlify.com/drop
2. ลากโฟลเดอร์ที่มี index.html ไปวางในหน้านั้น
3. จะได้ลิงก์เว็บทันที (เปลี่ยนชื่อเว็บได้ใน Site settings)

ทางเลือกอื่น
- GitHub Pages: สร้าง repository ใหม่ อัปโหลด index.html แล้วเปิด Settings > Pages
- เว็บโฮสติ้งของโรงเรียน: อัปโหลด index.html ไปไว้ในโฟลเดอร์ public_html

หมายเหตุ
- ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ภาษาไทย (Google Fonts) ถ้าออฟไลน์เกมยังเล่นได้ แต่ใช้ฟอนต์ของเครื่อง
- ความคืบหน้าของนักเรียนเก็บในเบราว์เซอร์ของแต่ละเครื่อง
- ระบบ VIP ตอนนี้ตรวจรหัสผ่านในตัวไฟล์ ยังไม่จำกัด 1 ID ต่อ 1 เครื่อง
  ถ้าต้องการล็อกเครื่อง ต้องต่อฐานข้อมูล (เช่น Firebase/Supabase) เพิ่มภายหลัง
- เสียงอ่านโจทย์ใช้เสียงของเครื่อง/เบราว์เซอร์ (Chrome และ Edge รองรับภาษาไทยดีที่สุด)
